Requested changes to the tool (front-end/usability and functionality) included:
- Landing page: reduce the “heavy load” of text and provide a clearer snapshot/short narrative at the top that explains what the tool shows and which policy documents are being compared.
- Visual design: add clearer signposting (e.g., large colored boxes/stronger color scheme); make key elements more visually obvious (e.g., make the whole checkbox area the color, not just a small circle).
- Navigation: make the top tabs/sections more obvious as navigation; potentially label as “page one/page two/page three”; add a back button / easier way to move back and forth; make section transitions clearer (e.g., change backdrop between areas).
- Labels: re-label tabs like “doc in focus / doc pairs / friction types” to more understandable user-facing wording.
- Charts: tweak the circular diagram(s) because one was hard to interpret (segmentation unclear); bring the bottom circular summary chart (policy vs number of targets) up to the top.
- Search: move the search bar to the top (from the bottom).
- Tutorial/onboarding: add a first-time guided tour/tutorial overlay (with next/skip) to explain what the tool is for, how to navigate, and how to read/interpret sections/visualizations.
- Access levels & sustainability: introduce different user access levels (e.g., some users can upload documents and cross-check; others cannot).
- Country customization: customize sector/taxonomy subcategories (e.g., align climate mitigation/adaptation sectors to Sri Lanka’s NDC/BTR sectors; possibly flag country-specific sectors in different colors).
- Scale/documents: interest in uploading all shared policies, subject to limits/costs driven by number of targets.
