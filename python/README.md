# CPC Tracker - Data Processing

Python scripts for processing policy documents and data.

## Setup

```bash
# Install uv (if not already installed)
curl -LsSf https://astral.sh/uv/install.sh | sh

# Create virtual environment and install dependencies
cd python
uv sync

# Activate environment
source .venv/bin/activate
```

## Scripts

- `src/` - Main processing scripts (coming soon)
- `tests/` - Test files

## Data Sources

Policy documents to be processed:
- NDC (Nationally Determined Contributions)
- NBSAP (National Biodiversity Strategies and Action Plans)
- NAP (National Adaptation Plans)
- Sectoral policies (agriculture, water, forest, land use)
